# Supplementary IVDD Result Deliverables

## Default descriptive analysis (unchanged)

The four default score cohorts and their 20-effect descriptive summary remain the only authoritative main-analysis results. Supplementary files in this section document that analysis; they do not recalculate or extend it.

- **S1:** isolated GSE251686 descriptive sensitivity. It remains outside the default summary; `GSM7986002` is permanently excluded after a Matrix Market stream-integrity failure.
- **S2:** cohort disposition, observation keys, identity checks, and default-summary eligibility.
- **S3:** locked program-module definitions and hashes.
- **S4:** default leave-one-key-out stability results.
- **S5a/S5b:** discovery retained-cell-threshold sensitivity.
- **S6:** reproducibility contract index.

S1--S6 do not provide confirmatory inference, replication, causal claims, biomarker claims, or therapeutic interpretation. The default summary contains no p-values or hypothesis tests.

## Supplementary Table S7: exploratory four-cohort NP meta-analysis

S7a--S7d are a separate cohort-level random-effects synthesis of the four default NP cohorts. They are exploratory supplementary analyses, not a replacement for the default descriptive analysis and not confirmation, replication, mechanism, biomarker, or therapy evidence. The four cohorts retain `confirmatory_eligible=false`; GSE251686 and `GSM7986002` remain outside S7.

## Supplementary Table S8: post-hoc six-cohort NP expansion

S8a--S8d are a separate post-hoc exploratory expansion of S7 that adds GSE186542 and the GSE167931 FPKM representation, for six cohort/module contrasts per module. The paired GSE167931 TPM representation is a same-sample processing sensitivity, not an additional cohort. S8 does not alter the unchanged 20-effect default analysis and is not independent patient-level validation.

## Supplementary Table S9: source-family replacement sensitivity

S9a--S9d replace the GSE167931 FPKM representation in S8 with the native GSE245147 Degenerated n=3 versus No-degenerated n=3 comparison. GSE167931 and GSE245147 are never pooled together because their source lab/author family overlaps and patient-level reuse cannot be excluded. S9 is a post-hoc source-family sensitivity only; it does not add a seventh independent cohort, alter the frozen default summary, or establish validation.

S7-S9 report HKSJ and four-module BH p-values only for transparent description; none can establish confirmation, replication, biomarker, mechanistic, causal, or therapeutic evidence.
