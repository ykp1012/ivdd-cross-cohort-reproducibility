# IVDD 跨队列分析结果简报

## 一句话结论

四个默认 NP 队列中，缺氧/氧化应激模块的高记录严重度组点估计均为正，但四个 Welch 95% 区间全部跨 0；因此目前得到的是一个需要后续验证的描述性方向模式，而不是稳健复现、普遍 IVDD 程序、机制或治疗靶点。S8 的六队列缺氧 SMDH 区间暂时离开 0，但 S9 用 GSE245147 替换 GSE167931 后重新跨 0，说明该结果对来源家族选择敏感，不能作确认性解释。

## 我们回答的问题

在不把细胞当作独立重复的前提下，四个预先锁定的 IVDD 转录程序，在不同公开人类队列中是否呈现一致方向，还是存在明显异质性？

## 做了哪些事情

1. 检索并核对 GEO 数据、SOFT 元数据、父项目/子系列关系、样本身份和分组信息。
2. 审计原始 10x 矩阵、压缩流完整性、barcode 与样本映射，并完成保守细胞 QC 和注释。
3. 预先锁定四个模块：ECM/胶原重塑、炎症/NF-kB、缺氧/氧化应激、椎间盘基质稳态；要求至少 80% 基因成功映射。
4. 以 donor 或明确标记的 presumed donor/sample/library key 为统计单位；细胞只作为嵌套观测。
5. 在每个队列内计算高记录严重度组减低记录严重度组的模块分数差，并给出 Welch 95% 区间、donor/library bootstrap 区间和 leave-one-key-out 稳定性。
6. 完成 20、30、50 个保留细胞阈值敏感性分析；24/24 个 discovery libraries 在三个阈值下均通过，最低 QC 通过细胞数为 471，96 个 library-module scores 和 8 个 AF/NP effects 均未改变。
7. 生成图表、补充材料、输入/输出哈希 manifest、正文草稿和研究质量审计。
8. 在默认结果冻结后，另行运行 S7 四队列探索性综合、S8 事后六队列扩展和 S9 来源家族替换敏感性；三者均使用 SMDH/REML/Knapp-Hartung，并仅透明报告 HKSJ 与四模块 BH p 值。

## 七张图告诉了什么

- **Figure 1**：逐队列显示四个 NP 模块的效应点和 Welch 95% 区间。缺氧/氧化应激在四个默认队列的点均在 0 的同一侧，但区间都跨 0。
- **Figure 2**：显示 NP 方向对齐矩阵。只有缺氧/氧化应激出现四队列同向的点估计；其余模块方向不一致。
- **Supplementary Figure S1**：GSE251686 的隔离敏感性分析。缺氧/氧化应激点估计为 -0.0778，Welch 95% 区间为 [-1.7214, 1.5658]，不支持把该队列当作默认复制证据。
- **Supplementary Figure S2**：展示队列纳入、排除和解释边界，明确 GSE230809 子系列合并以及 GSE251686 隔离。
- **Supplementary Figure S3**：S7 四队列随机效应综合；图中 SMDH 与 HKSJ 区间仅作探索性描述。
- **Supplementary Figure S4**：S8 事后六队列扩展；缺氧模块的 SMDH 为 0.7694，95% CI [0.1706, 1.3682]，但不能解释为确认性结果。
- **Supplementary Figure S5**：S9 来源家族替换；缺氧 SMDH 为 0.5746，95% CI [-0.7231, 1.8723]，显示 S8 的方向与区间不稳健。

## 能够支持的解释

- 公开 IVDD 队列之间存在明显的队列级异质性。
- 缺氧/氧化应激值得作为后续独立队列和实验验证的候选程序。
- 以 donor/sample key 为单位并报告区间，比把大量细胞当作独立样本更能反映当前证据强度。

## 当前不能声称的内容

不能称为“已复制/已验证的生物标志物”、普遍 IVDD 程序、驱动基因、因果机制或治疗靶点。默认 20-effect 主分析本身没有 p 值或正式 meta-analysis；S7-S9 虽透明报告 HKSJ/BH p 值，但三者均为非确认性补充综合，也不能替代独立患者级验证。项目没有进行 ROC、WGCNA/hub gene、CellChat、分子对接或因果推断。
